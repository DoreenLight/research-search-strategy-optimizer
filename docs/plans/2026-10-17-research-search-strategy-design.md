# Research Search Strategy Optimizer：已批准设计

- 日期：2026-10-17
- 状态：用户已批准
- 版本：P0 design v1
- 范围：Skill + Python；先完成 P0，同时保留 P1—P4 路线图

## 1. 产品定位

本项目不是一次性关键词生成器，而是一个将自然语言科研意图转换为有真实文献证据支撑、可执行、可追溯、可评估检索策略的 Agent Skill。

核心链路：

```text
科研问题 → 研究意图与概念维度 → 候选术语 → 真实文献证据
        → 术语关系与来源 → 数据库无关检索逻辑
        → 数据库适配查询 → 论文、证据、日志与评测
```

差异化重点是证据和检索审计，而不是生成更多同义词。

## 2. P0 范围

P0 必须支持：

1. 研究范围结构化：研究对象、输入、任务、方法、应用、明确约束、未说明事项。
2. 候选术语建模：概念维度、关系类型、来源类型、术语证据状态、检索测试状态。
3. OpenAlex Works 元数据检索和结果记录；API 限制、错误和部分成功必须进入日志。
4. 从论文标题、摘要、作者关键词和数据库标签提取候选术语；字符串统计和去重由 Python 完成，语义等价判断由 Agent 辅助并保留人工/模型状态。
5. 生成 `exploratory`、`focused`、`method_specific` 三类数据库无关检索逻辑，并提供 OpenAlex 适配形式。
6. 输出标准化 Research Search Package：研究范围、术语库、论文记录、策略、执行日志、评测报告。
7. 离线测试、固定样本检查和真实接口检查的结果分开记录。

P0 不包括：自动多轮优化、PubMed/MeSH 或 Semantic Scholar 真实接入、引文网络、全文获取、向量库、前端、多 Agent、自动注册或公网发布。

## 3. 模块职责

### Skill 入口

只定义触发边界、执行顺序、证据约束、输出契约和失败降级。动态科研事实不写入主文件。

### LLM / 宿主 Agent

负责理解中文科研描述、生成初始候选词、提出概念关系、解释结果和辅助相关性判断。

### Python

负责 API 请求、重试、速率限制、原始响应、Schema 校验、关键词统计、确定性归一化、标识去重、查询构造、指标计算和日志。

## 4. 核心数据原则

每个对象带 `schema_version` 和稳定 ID。

- 研究范围不把未说明约束变成强制过滤条件。
- 术语证据和检索测试是两个独立维度。
- 作者关键词、数据库关键词、模型生成词和受控词表词保留独立来源。
- 论文元数据不补写摘要、标识符或作者。
- 数据库返回总命中数、实际获取数量、去重数量分别记录。
- 模型相关性判断不能冒充人工真值。
- 同一个候选词未单独测试时，只归因于策略版本，不归因于单词收益。

## 5. 证据等级

- A：官方文档、原始 API 响应、论文原文、权威词表。
- B：研究机构指南或方法明确的可靠二手来源。
- C：社区/媒体线索，须保留待核验状态。
- U：模型生成的未核验候选。

每条证据记录 URL 或记录 ID、来源类型、等级、获取日期、定位字段和支持的判断。

## 6. 评测

### 工程正确性

覆盖 Schema、抽取、去重、查询构造、指标、空结果、超时、限流、权限错误和部分成功。

### 真实接口

检查查询是否真正执行、响应是否能追溯、术语是否能定位到论文字段、失败是否如实记录。只导出未执行的数据库语法不能称为真实接口验证。

### 检索效果

预留 A：少量人工词、B：LLM 一次生成、C：数据库原生能力、D：证据支撑策略四类对照。P0 可比较初始策略与证据增强策略，但不宣称已经实现自动多轮闭环。

主要指标：已知相关论文覆盖率、Precision@K（有足够标注时）、新增相关论文收益、证据可追溯率、复现性和成本。没有独立人工标注集时，结果标为探索性。

## 7. 错误和安全

- 网络错误：有限重试、超时、限流等待，并区分失败、空结果和部分成功。
- 字段缺失：只分析实际字段，不补写缺失事实。
- 凭证：只从环境变量读取，不写入日志和交付物。
- 成本：默认预算；P0 不调用收费的文本标注端点。
- 复现：保存输入、策略版本、配置、数据快照和运行记录。
- 权限：不自动获取付费全文、不自动注册全局技能、不发布公网。

## 8. 验收

P0 只有在以下内容都有实际记录时才算完成：

- 中文科研描述可结构化。
- 至少一个真实文献数据源可成功或明确失败并有日志。
- 三类策略可生成并通过本项目的逻辑检查。
- 关键词、论文、证据、检索执行和评测可以互相追溯。
- 工程测试、接口检查和技能流程检查均有报告。
- 报告清楚区分已做、未做、失败、推断和未核验。
