研究判断

做什么

将 LLM 的语义理解与 Python 的确定性操作分开：模型负责概念解释，脚本负责请求、去重、计数、查询和日志。

证据可追溯数据库无关逻辑可重复评测

暂时不做什么

不把关键词数量当成功，不把推荐列表当完整检索，不把未登录产品的宣传数字当实际效果，不在 P0 引入收费文本标注端点。

不伪造完整覆盖不混淆计划与执行

路线图

  1. P0
    证据支撑的策略生成

    意图契约、OpenAlex 元数据、术语证据、三类查询、执行日志和工程评测。

  2. P1
    闭环优化

    多轮版本、遗漏分析、增量收益、停止和回退规则。

  3. P2
    多数据库与独立发现

    PubMed/MeSH、Semantic Scholar、引文扩展和跨源去重。

  4. P3
    科研工作流集成

    合法论文获取、阅读工作台、增量更新。

  5. P4
    质量强化与可选产品化

    多领域基准、人工审阅和是否前端化的证据决策。
